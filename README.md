# StuCrs-Book


[**StuCrs**](https://github.com/chitono/StuCrs) フレームワークのドキュメントを作成、公開するためのリポジトリ。

## ドキュメント一覧

- [『StuCrsドキュメント・基礎編』](https://chitono.github.io/StuCrs-Book/book-basic/)
  
  Rust言語のみを用いてなるべく既存のライブラリに頼ることなく、深層学習のフレームワークを構築していきます。
  行列計算やフレームワークの根幹となる自動微分による逆伝播や最適化関数、損失関数などを一から実装し、最終的にMNISTの学習に挑みます。    
  
- [『StuCrsドキュメント・CNN編』](https://chitono.github.io/StuCrs-Book/book-cnn/)
  
  基礎編の続編として、フレームワークにCNNの機能を導入します。Im2col,Col2im関数を発展させてConv2d,Maxpool関数を実装し、最終的にCNNによるMNISTの学習を目指します。   

## 今後の展望
現在のドキュメントから発展させた内容(例：CUDAによるGPU行列計算対応、行列計算ライブラリ、フレームワークとしてのさらなる実用化など、)に関して新たにドキュメントを作成し、皆さんとぜひ考えを共有していきたいと考えています。
