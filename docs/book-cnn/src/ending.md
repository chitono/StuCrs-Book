# 終わりに

以上で深層学習のフレームワークの基礎の説明は終了となります。データの分析や画像認識といったAIの技術に対しての見方が少し変わったのではないでしょうか。このドキュメントは、TensorFlowやPyTorchといった既存のフレームワークをただ外部のAPIとして使うだけでは物足りず、これらのフレームワークの中身、そして理論、構造を探究しようとする人たちとともに、Rustを通した深層学習の原理を考え、発展させようとする試みのもと書かせていただきました。私といたしましても、このドキュメントを書くにあたり、自分でゼロから実装していく過程で自分なりに考えたことを自分の言葉で書くということで、自分の思考を再び捉えなおす機会となりました。このドキュメントやその他のリポジトリを通じてこの分野、研究の奥深さ、おもしろさを共有する方が一人でも出てきてくれるならば、私としてはうれしい限りです。
